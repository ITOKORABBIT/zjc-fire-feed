# zjc-fire-feed

新竹市消防局「119 即時案件」的資料轉存工具。

- 來源：<https://119.hcfd.gov.tw/DTS/caselist/html>（新竹市消防局公開頁面）
- 每 10 分鐘抓取一次，解析成結構化的 `fire-cases.json`
- 供 <https://zjc-helper.pages.dev> 讀取顯示

## 為什麼需要這個轉存

來源是一頁 HTML 表格，沒有提供 JSON 介面，也沒有跨來源存取標頭，
瀏覽器無法直接讀取。因此自建這支抓取工具：定時取得公開頁面、
解析成結構化資料，網站再讀這份轉存結果。

抓取頻率為每 10 分鐘一次，僅取用該頁面公開顯示的欄位，
不做任何登入或非公開資料的存取。

本倉庫只存放公開的政府資料與抓取腳本，不含網站原始碼。
